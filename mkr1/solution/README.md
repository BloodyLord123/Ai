# AI-асистент перевірки лабораторних робіт

## Встановлення та запуск

1. Перейдіть у папку `solution` та встановіть залежності:
   
   cd solution

   py -m pip install -r requirements.txt

   py main.py
   
3. (Опціонально) Створіть файл .env  у папці solution та вкажіть ваш ключ GEMINI_API_KEY="ВАШ КЛЮЧ" (або введіть його безпосередньо у вікні програми)
